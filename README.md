# Telecom Traffic Monitor

## Description
MVP Cloud-Native de suivi et d'analyse de consommation
de données télécom.

## Architecture
- PostgreSQL : stockage des données.
- FastAPI : API backend.
- Nginx : reverse proxy.
- Docker Compose : orchestration des conteneurs.

## Statut
Projet en cours de développement.

## Important
Les données de trafic utilisées sont simulées.
Ce projet ne réalise pas de véritable inspection DPI
ni de capture de paquets réseau.
